# Network fees explained

## What a network fee is

A network fee (sometimes called gas on Ethereum) is paid to the validators or miners of a blockchain to include a transaction. It is set by the network, not by OpenCrypto, and it is charged in the network's native asset. It applies when assets move on a blockchain, such as a withdrawal to an external wallet.

## Network fee versus application fee

The application fee is OpenCrypto's own charge on swaps: 0.25% of the amount spent. A network fee is a separate cost of using a blockchain. Swaps inside OpenCrypto never touch a blockchain, so a swap quote has an application fee but no network fee. If a single screen ever shows two fees, check which is which before adding them together.

## Simulated network fee estimates

The platform publishes simulated estimates per network, for example Bitcoin 0.00012 BTC, Ethereum 0.0015 ETH, Arbitrum One 0.0002 ETH, Solana 0.01 SOL, Dogecoin 5 DOGE and USDT on Tron 1 USDT. The full list is in the supported assets reference. Real networks change fees constantly with congestion; these values are fixed teaching numbers.

## Scope of this page

This page explains fees only. It is not a withdrawal policy and does not describe limits, processing times or eligibility for withdrawals.
